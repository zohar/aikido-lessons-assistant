    Nouvelle séance

    Importer un JSON

    Décrivez la séance comme dans un message, ou cliquez sur les éléments ci-dessous pour les ajouter. Sans précision, la séance est pour 5e à 1er kyu, adultes, et dure 30 minutes. Comptez 4 à 8 minutes de rédaction ; inutile de rester sur la page.

    Ctrl + Entrée pour envoyer

    Importer une séance

    Rédiger plutôt

    Collez le bloc JSON d'une séance (par exemple celui que propose l'assistant dans le projet Claude, ou un JSON copié avec « Copier le JSON »), ou choisissez un fichier .json. La séance est vérifiée avec les mêmes règles que les séances rédigées ici, puis ajoutée à « Mes séances ».

    ou déposez le fichier dans la zone ci-dessus
